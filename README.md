# Todo List Project

## 프로젝트 소개

간단한 할 일 관리 프로그램입니다.

사용자는 할 일을 추가, 조회, 삭제할 수 있으며, 프로그램 종료 후에도 파일에 저장되어 데이터가 유지됩니다.

---

## 개발 환경

* Visual Studio Code
* Git
* GitHub

---

## 주요 기능

### 할 일 추가

새로운 할 일을 등록할 수 있습니다.

### 할 일 조회

등록된 할 일 목록을 확인할 수 있습니다.

### 할 일 삭제

선택한 할 일을 삭제할 수 있습니다.

### 파일 저장

할 일 목록을 파일에 저장하여 프로그램 종료 후에도 유지됩니다.

### 파일 불러오기

프로그램 시작 시 저장된 데이터를 자동으로 불러옵니다.
